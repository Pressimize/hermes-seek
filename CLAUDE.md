# Notes for Claude Code

Seek is one half of a pair with [Sift](https://github.com/Pressimize/hermes-sift), which does the same for `web_extract`. Both follow the same conventions (settings, log and error prefixes, key masking, release steps). When you change one of them here, check whether Sift needs the same change.

Earlier reviews and the points they settled are in `docs/reviews/`. Read them before raising a point again.
